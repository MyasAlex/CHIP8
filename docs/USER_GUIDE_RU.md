# CHIP-8 Studio: инструкция игроку

## Скачать и запустить

Скачайте **CHIP8-Studio-Windows-x64.zip** со [страницы последнего релиза](https://github.com/MyasAlex/CHIP8/releases/latest), распакуйте весь архив и откройте **CHIP8.Emulator.exe**. Целевая система — Windows 10/11 x64. Игры и демонстрация встроены в EXE.

При запуске открывается Pong на двоих: **W/S** — левая ракетка, **↑/↓** — правая. В меню **Игры** доступны классический Pong с соперником из ROM, Breakout и демонстрация. Во встроенном Pong на двух игроков бота нет.

## Открыть свою игру

Нажмите **Ctrl+O**, перетащите ROM в окно или передайте путь аргументом командной строки.

Поддерживаются .ch8, .rom, .sc8, .xo8. .sc8 включает Super-CHIP; .xo8 и ROM размером больше 3584 байт — XO-CHIP. Обычный .ch8 использует Modern, если для него ранее не сохранён другой профиль. Определения совместимости по базе хешей пока нет.

## Клавиши

| Действие | Клавиша |
| --- | --- |
| Открыть ROM | Ctrl+O |
| Пауза / перезапуск | P / F1 |
| Сохранить / загрузить | F5 / F8 |
| Перемотка назад | Backspace |
| Снимок PNG | F6 |
| Шаг по кадру / инструкции | F9 / F10 |
| Полный экран / вернуться в окно | F11 / Esc |
| Отладка / выключить звук | F12 / M |

Физические ряды **1234 / QWER / ASDF / ZXCV** соответствуют CHIP-8 **123C / 456D / 789E / A0BF**. Русская раскладка сохраняет управление. Какие именно клавиши использует игра, определяет её ROM.

В Pong первый XInput-геймпад управляет левой ракеткой, второй — правой; работают D-pad вверх/вниз и левый стик. В других ROM D-pad/стик соответствуют 5/8/7/9, A/B/X/Y/Start — 6/4/0/F/A.

## Скорость, профиль и мерцание

Для классического Pong и Breakout задано 700 инструкций/с, для встроенного Pong на двоих — 6000. Скорость CPU меняет темп выполнения ROM; таймеры продолжают работать на 60 Гц.

Выбирайте VIP, Modern, Super-CHIP Modern или XO-CHIP по требованиям игры. Изменение особенностей инструкций перезапускает ROM. Профиль, особенности и скорость запоминаются отдельно для каждого ROM.

Стабилизация XOR включена по умолчанию. Она временно удерживает стёртый спрайт до повторной отрисовки, уменьшая пропадания в некоторых старых играх. Для тестов или намеренного мигания используйте точный экран. Память и столкновения ROM не меняются; без повторной отрисовки спрайт исчезнет не позднее четырёх границ кадра, максимум через 66,7 мс.

## Сохранения и снимки

Данные находятся в **%LOCALAPPDATA%\\CHIP8Studio**. Команда **Файл → Папка данных** открывает эту папку. Если Local AppData недоступна, используется userdata рядом с EXE.

F5 сохраняет состояние текущего ROM, F8 проверяет и загружает его. Повреждённое сохранение и файл от другого ROM отклоняются. Скорость CPU остаётся из текущих настроек приложения. Перемотка хранит до 31 снимка в памяти с интервалом около секунды.

## Если возникла проблема

| Симптом | Что проверить |
| --- | --- |
| Кнопки не работают | Щёлкните по окну, посмотрите управление конкретного ROM и проверьте паузу клавишей P. |
| Старая игра мерцает | Включите стабилизацию XOR и попробуйте исходную скорость и профиль игры. |
| В тесте исчезло намеренное мигание | Выберите точный экран. |
| ROM остановился с ошибкой инструкции | Проверьте профиль и расширение; сохраните текст ошибки для отчёта. |
| Нет звука | Нажмите M, проверьте громкость и устройство вывода Windows. Звук появляется, когда ROM активирует звуковой таймер. |

[Сообщите об ошибке](https://github.com/MyasAlex/CHIP8/issues/new?template=bug_report.yml), указав версию приложения, Windows, название или легальный источник ROM, профиль, скорость CPU и действия до сбоя. Для ошибок отображения полезен PNG или короткое видео.
