# CHIP-8 Studio 3.0: инструкция игроку

Распакуйте **весь** [архив Windows x64](https://github.com/MyasAlex/CHIP8/releases/latest/download/CHIP8-Studio-Windows-x64.zip), включая `roms/catalog`, и запустите **CHIP8.Emulator.exe**. В первый раз откроется Pong на двоих: W/S — слева, ↑/↓ — справа. Затем приложение может продолжать последнюю игру с автосохранения.

Нажмите **Библиотека** или **Ctrl+L**. В комплекте 210 уникальных игр, демо и программ с поиском, обложками, избранным и недавними запусками. С оригинальными программами Studio библиотека содержит 212 записей. Это не полный исторический архив; 11 каталоговых ROM требуют других платформ и отмечены отдельно.

**[Полная инструкция версии 3.0 →](STUDIO_3_RU.md)**

| Действие | Клавиша |
| --- | --- |
| Открыть один ROM / добавить несколько | Ctrl+O; также перетаскивание |
| Библиотека | Ctrl+L |
| Пауза / начать заново | P / F1 |
| Сохранить / загрузить выбранный слот | F5 / F8 |
| Перемотка | Удерживать Backspace; можно перетаскивать шкалу |
| Ускорение / замедление | Удерживать Tab / Ctrl |
| Снимок PNG / полный экран | F6 / F11 |
| Отладка / инструкция / кадр | F12 / F10 / F9 |
| Звук | M |

Настройки клавиш и виртуальная клавиатура находятся в **Эмуляция**. Обычные физические ряды `1234 / QWER / ASDF / ZXCV` соответствуют CHIP-8 `123C / 456D / 789E / A0BF`; русская раскладка работает. Для известных ROM стрелки, пробел, Enter и геймпад дополнительно используют управление из базы.

**Экран:** Оригинал показывает точный буфер, Стабильный сглаживает промежуточные XOR-стирания, Плавный добавляет послесвечение. CRT включается отдельно. Для игры без следов оставьте Стабильный. Эффекты не меняют память и столкновения; стабилизация может задерживать исчезновение до 66,7 мс.

**Файл:** 10 слотов на ROM, автосохранение каждые 30 секунд и при выходе, автопродолжение, перенос настроек и портативный режим. F1 начинает заново. Перемотка сохраняет до 120 секунд, с пределом хранилища 64 МиБ; интенсивные изменения памяти могут сократить историю.

**Запись:** GIF и MP4 со звуком до двух минут виртуального времени. Для MP4 нужны системные кодеки Media Foundation; при их отсутствии используйте GIF. Повтор ввода начинается с перезапуска ROM и проверяет состояние каждого кадра.

**Диагностика:** точки останова, память по HEX-адресу, журнал инструкций, сравнение точного и стабилизированного кадра и текстовый отчёт.

Данные находятся в `%LOCALAPPDATA%\CHIP8Studio`; в портативном режиме — `userdata` рядом с EXE. Открыть папку: **Файл → Папка данных и снимков**.

Если игра остановилась или выглядит неправильно, проверьте профиль и режим экрана. При потере управления проверьте фокус и паузу P. Для сообщения об ошибке сохраните отчёт и, по возможности, повтор ввода: [GitHub Issues](https://github.com/MyasAlex/CHIP8/issues/new?template=bug_report.yml). Происхождение ROM и исходные уведомления сохранены в [THIRD_PARTY.md](../THIRD_PARTY.md).
