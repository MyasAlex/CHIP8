# CHIP-8 Studio 3.0

Распакуйте **весь ZIP**, включая `roms/catalog`, и запустите **CHIP8.Emulator.exe**. Windows 10/11 x64; устанавливать компилятор не нужно. При первом запуске открывается Pong на двоих; затем можно продолжать последнюю игру с автосохранения. Для каталога нажмите **Библиотека** или **Ctrl+L**.

## Библиотека

В комплекте 210 уникальных ROM из CHIP-8 Community Archive и классической коллекции: игры, демо и тестовые программы. Вместе с оригинальными Pong на двоих и демонстрацией Studio библиотека показывает 212 уникальных программ. Это не все когда-либо выпущенные игры: единого полного архива нет, появляются новые программы, а условия распространения различаются.

Для 199 ROM подобраны профили CHIP-8 / Super-CHIP / XO-CHIP. Остальные 11 отмечены как требующие другой платформы и не запускаются в неподходящем режиме. Проверка запуска первых пяти секунд всех 199 ROM не означает проверки полного прохождения или аппаратной точности.

В библиотеке есть поиск по названию, автору и платформе, звёздочка избранного, фильтр недавних игр и время игры. Колесо мыши или стрелки внизу переключают страницы. Правая кнопка на карточке показывает описание и SHA-1. Время учитывается только при выполнении игры, в секундах виртуального времени.

**Ctrl+O** открывает один ROM или добавляет несколько выбранных файлов. Несколько ROM можно перетащить в окно. **Файл → Импортировать папку ROM** обходит вложенные папки с `.ch8`, `.sc8`, `.xo8`, `.rom`. Импорт копирует новые файлы в папку данных, поэтому исходные ROM остаются на месте. Повторные экземпляры определяются по SHA-1.

По содержимому ROM выбираются профиль, особенности инструкций, скорость, цвета и управление из базы 547 известных SHA-1. Настройки пользователя имеют приоритет. Для неизвестных ROM используются расширение и размер файла; это предположение, которое можно изменить в меню **Эмуляция**.

## Управление

| Действие | Клавиша или меню |
| --- | --- |
| Библиотека / импорт ROM | Ctrl+L / Ctrl+O |
| Пауза / начать заново | P / F1 |
| Сохранить / загрузить текущий слот | F5 / F8 |
| PNG-снимок | F6 |
| Полный экран / вернуться | F11 / Esc |
| Отладка / инструкция / кадр | F12 / F10 / F9 |
| Звук | M |
| Перемотка назад | Удерживать Backspace или перетаскивать шкалу |
| Ускорение / замедление | Удерживать Tab для 4× / Ctrl для 0,25× |
| Постоянное ускорение или замедление | Эмуляция → соответствующий режим |
| Переназначение клавиш | Эмуляция → Переназначить 16 клавиш |
| Экранные кнопки | Эмуляция → Виртуальная клавиатура |

Pong на двоих: **W/S** — левая ракетка, **↑/↓** — правая. У этой игры нет бота. Исходный Pong содержит собственного соперника.

Обычная CHIP-8 клавиатура `123C / 456D / 789E / A0BF` соответствует физическим рядам `1234 / QWER / ASDF / ZXCV`. Для известной игры стрелки, пробел и Enter дополнительно соответствуют её направлениям и кнопкам A/B. XInput использует те же направления из базы; в Pong первый геймпад управляет левой ракеткой, второй — правой.

Переназначение проходит по клавишам CHIP-8 от 0 до F. Нажмите 16 разных физических клавиш; **Esc** отменяет всё изменение. Назначение сохраняется для текущего ROM и заменяет автоматические клавиатурные подсказки. P, M, Tab, Ctrl, Backspace, Esc и функциональные клавиши остаются для команд приложения. Экранные кнопки удерживаются мышью и освобождаются при потере фокуса.

Ускорение меняет темп виртуального времени целиком: CPU, таймеры и ввод идут вместе. Настройка «Скорость CPU» меняет число инструкций внутри виртуальной секунды; игровые таймеры остаются 60 Гц.

## Экран и мерцание

| Режим | Поведение |
| --- | --- |
| Оригинал | Точный экран ROM; отключает стабилизацию, послесвечение и CRT. |
| Стабильный | Стабилизация промежуточного XOR-стирания отдельных спрайтов. Режим по умолчанию. |
| Плавный | Стабилизация плюс короткое послесвечение. |
| CRT | Отдельно включаемые линии, свечение соседних пикселей и виньетка; интенсивность 0–100%. |

Память, флаги столкновений и инструкции не зависят от этих эффектов. Стабилизация может задержать непарное исчезновение до 66,7 мс; послесвечение намеренно оставляет короткий след. Для диагностики выбирайте **Оригинал**. Для обычной игры без следов используйте **Стабильный**.

Доступны восемь палитр. Выбор ручной палитры отключает цвета ROM; **Экран → Цвета из базы ROM** возвращает авторские цвета. PNG и запись используют выбранные эффекты.

## Сохранения и перемотка

У каждой игры 10 слотов. **Файл → Текущий слот** выбирает слот для F5/F8; номер запоминается отдельно для ROM. Рядом с новым сохранением создаётся PNG-превью. Старое одиночное сохранение версии 2.1 доступно через слот 1. Повреждённые файлы и сохранения от другого ROM отклоняются.

Автосохранение происходит каждые 30 секунд виртуального времени, при смене ROM и закрытии окна. Включение автосохранения и автоматическое продолжение настраиваются отдельно. **F1** всегда начинает заново.

История хранит состояния каждые два кадра, то есть 30 раз в секунду. Выберите 30, 60 или 120 секунд в меню **Эмуляция → Длина истории**. Используются полные снимки и сжатые разности; хранилище ограничено 64 МиБ. При интенсивном изменении памяти доступная история может быть короче выбранного предела. Она хранится только во время текущего запуска игры.

Удерживайте **Backspace**: время идёт назад с темпом около 4×. Отпустите — игра продолжится, если до перемотки не была на паузе. Шкалу можно перетаскивать. После выбора прошлого будущая ветка удаляется. Клавиши освобождаются, чтобы восстановление не оставило зажатое управление. Состояние CPU и фаза планировщика восстанавливаются; визуальные удержания спрайтов заново формируются при продолжении.

## GIF, MP4 и повторы ввода

Меню **Запись** начинает GIF 256×128 или MP4 512×256 с частотой 30 кадров/с. GIF использует палитру из 256 цветов; MP4 — H.264 и моно AAC 48 кГц со звуком эмулятора. Завершите запись через **Запись → Завершить GIF / MP4**. При смене ROM, перемотке или закрытии окна файл завершается автоматически.

Предел — около двух минут виртуального времени; GIF также ограничен 128 МиБ. Пауза не записывается, ускорение и замедление влияют на скорость накопления записи. MP4 использует системную Media Foundation. Если она отсутствует, например в некоторых Windows N без Media Feature Pack, приложение остаётся работоспособным и позволяет GIF. Запись экрана содержит только игровое изображение.

**Записать ввод** перезапускает ROM и запоминает исходное состояние, RNG, скорость CPU, нажатия и контрольную сумму каждого кадра. **Завершить запись / повтор ввода** сохраняет `.c8replay`. Максимум — 20 минут. Файл содержит ROM и всё необходимое для повтора на этой версии эмулятора; он не отправляется в интернет.

**Открыть повтор ввода** воспроизводит записанные нажатия и сравнивает контрольные суммы. При расхождении выполнение останавливается с номером кадра. Во время повтора реальные игровые нажатия и точки останова не вмешиваются в запись. Смена ROM, профиля, скорости, загрузка состояния и перемотка завершают запись или повтор. Сохраните отчёт, если нужно передать воспроизводимую ошибку.

## Диагностика и достижения

F12 показывает регистры, таймеры, дизассемблер и память. Изменившиеся за последний шаг/кадр группы регистров подсвечиваются. **Диагностика → Показать память по адресу** принимает HEX-адрес; PgUp/PgDn двигают просмотр на 32 байта.

Точки останова задаются HEX-адресом и останавливают CPU перед инструкцией. Повторное добавление удаляет точку. P продолжает выполнение; F10 выполняет инструкцию. Журнал хранит последние 1024 попытки выполнения инструкций с регистрами до шага, пока панель отладки включена. **Экспортировать отчёт** пишет информацию о ROM, профиле, регистрах, ошибке и журнале в текстовый файл.

**Сравнение экранов** сохраняет PNG: слева точный буфер ROM, справа кадр после стабилизации, без CRT и послесвечения. Это удобно для диагностики промежуточных стираний. Локальные достижения: первое очко, 3 и 10 очков в оригинальном Pong на двоих и первый PNG-снимок. Они сохраняются на компьютере.

Счётчик FPS показывает число виртуальных кадров за секунду реального времени. CPU — доля процессорного времени приложения от общей мощности системы. Это показатели работы эмулятора, а не измерение аппаратного VSync.

## Перенос данных

По умолчанию данные находятся в `%LOCALAPPDATA%\CHIP8Studio`. Открыть папку: **Файл → Папка данных и снимков**.

**Экспорт настроек, ROM и сохранений** создаёт `.c8pack` с настройками, слотами, автосохранениями, RPL и импортированными ROM. Сам общий каталог поставляется с ZIP программы; видео, повторы и PNG в пакет настроек не входят. Предел пакета — 64 МиБ. Импорт проверяет контрольную сумму и допустимые имена файлов, затем заменяет соответствующие данные и перезапускает текущую игру с импортированными настройками.

**Портативный режим** переносит данные в `userdata` рядом с EXE и создаёт `portable.ini`. При отключении данные копируются обратно в Local AppData. Старые папки сохраняются. Папка EXE должна быть доступна для записи. Для переноса портативного экземпляра копируйте всю папку приложения вместе с `userdata` и `portable.ini`.

## Следующий этап

В 3.0 не реализованы CHIP-8X, Super-CHIP Legacy, MegaChip, аппаратная тактовая эмуляция COSMAC VIP / HP48 и редактор игр. Они требуют отдельных ядер, спецификаций и проверок. База помогает подобрать интерпретатор, но не превращает Modern Super-CHIP в точную эмуляцию исторического HP48.

Оригинальные уведомления и происхождение ROM: [THIRD_PARTY.md](../THIRD_PARTY.md) и [SOURCES.json](../roms/catalog/SOURCES.json). Ошибки: [GitHub Issues](https://github.com/MyasAlex/CHIP8/issues).
