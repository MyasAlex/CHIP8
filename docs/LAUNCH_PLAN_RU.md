# Запуск CHIP-8 Studio с нуля

Цель первого этапа — получить первых 50 скачиваний Windows ZIP и несколько конкретных отзывов. Это рабочая цель, а не обещание количества скачиваний.

## Что подготовлено

- Прямая ссылка на готовую Windows-версию, инструкции на английском и русском.
- Демонстрационный GIF, изображение игры и карточка для анонса.
- Двуязычные заметки релиза и история изменений.
- Автоматическая сборка, проверки и упаковка ZIP с SHA-256.
- Формы ошибки и предложения; инструкция участнику.
- Тексты анонсов и технической статьи в [ANNOUNCEMENTS.md](ANNOUNCEMENTS.md).

## Первые две недели

| Когда | Действие | Какой результат искать |
| --- | --- | --- |
| День 1 | Проверить скачивание ZIP на Windows, запуск и две встроенные игры. Использовать одну ссылку на последний релиз во всех анонсах. | Пользователь доходит от ссылки до работающей игры. |
| День 2 | Опубликовать технический текст в сообществе разработчиков эмуляторов, например r/EmuDev, после проверки его актуальных правил. Приложить GIF и описание решения мерцания. | Содержательные отзывы о реализации и совместимости. |
| День 3 | Разместить русский короткий пост в собственном аккаунте или подходящем сообществе, где разрешены проекты участников. | Первые игроки и понятные вопросы о запуске. |
| Дни 4–7 | Ответить на отзывы и воспроизвести найденные ошибки. Попросить назвать ROM, профиль и скорость. | Воспроизводимые отчёты и исправления. |
| Дни 8–10 | Снять короткое видео настоящего окна: запуск, сохранение и перемотка. | Видно, зачем пользоваться приложением. |
| Дни 11–14 | Выпустить небольшой релиз по реальным отзывам и обновить анонс только при заметном изменении. | Новая версия решает конкретную проблему игрока. |

Технический анонс для r/EmuDev описывает разработку, XOR-рисование и проверки. Тексты для внешних площадок подготовлены как черновики; владелец публикует их со своего аккаунта.

## Что считать

Считать скачивания **CHIP8-Studio-Windows-x64.zip**, а не сумму ZIP, SHA256SUMS.txt и build-info.json. Скачивание файла не равно уникальному человеку или установке.

```sh
python scripts/download_stats.py
```

Скрипт читает публичные данные релизов GitHub и выводит число скачиваний Windows ZIP по версиям. При ограничении API можно посмотреть каждый релиз вручную и повторить запрос позднее.

Полезно раз в неделю записывать: скачивания ZIP, новые отчёты, воспроизводимые ошибки, время ответа и исправления. Звёзды показывают интерес, но не заменяют сведения о запуске и играх.

## Следующие улучшения выбирать по отзывам

- Английский интерфейс, если приходит англоязычная аудитория.
- Подсказки управления конкретной игры, если игроки не находят нужные клавиши.
- Проверенная база профилей ROM, если основная проблема — совместимость.
- Настройки стабилизации для конкретной игры, если визуальные эффекты требуют другого поведения.
- Установка через менеджер пакетов, если появляется регулярный спрос.

Не покупать звёзды или скачивания: они не помогают понять, запускается ли программа и возвращаются ли игроки. Один небольшой полезный релиз по отзывам — повод для содержательного повторного анонса.
