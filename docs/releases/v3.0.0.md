## CHIP-8 Studio 3.0

Download **CHIP8-Studio-Windows-x64.zip**, extract the whole archive and open **CHIP8.Emulator.exe**. Windows 10/11 x64. Keep `roms/catalog` beside the EXE for the offline library. The application interface is in Russian; bilingual player guides are included.

- Offline library: 210 unique ROM programs from two collections, original notices and covers, search, favorites, recent games and playtime. Eleven entries require other platforms and are marked accordingly.
- Automatic profiles, quirks, speed, colors and controls for 547 known SHA-1 fingerprints; saved user choices take priority.
- Exact, stable and phosphor presentation; optional CRT effects and eight palettes.
- Ten slots per ROM, autosave/resume, continuous rewind up to 120 seconds with a 64 MiB storage limit and a draggable timeline.
- Turbo 4× / slow motion 0.25×, per-game keyboard remapping and mouse keypad.
- GIF and H.264/AAC MP4 recording; deterministic input replay with a checksum for every frame.
- Breakpoints, memory browsing, instruction trace, register-change highlighting, comparison PNG and exported reports.
- Settings/save/managed-ROM transfer, explicit portable mode and local Pong achievements.

Verification includes 51 core test groups, 31 offline Timendus reference scenarios, bounded five-second boot checks for all 199 launchable catalog profiles, independent GIF decoding, and native Windows checks of the interface, timeline, slots, replay, export/import and H.264/AAC capture. Boot checks are not complete game playthroughs. Physical controllers, speakers and hardware VSync still need checking on the target machine.

This is not an exhaustive archive of every historical CHIP-8 ROM. CHIP-8X, Super-CHIP Legacy, MegaChip, cycle-level VIP/HP48 and a game editor remain future work. Emulator code is MIT; bundled guest programs retain their own distribution terms in **THIRD_PARTY.md** and the source collection notices.

## По-русски

Распакуйте весь **CHIP8-Studio-Windows-x64.zip** и запустите **CHIP8.Emulator.exe**. Нажмите **Библиотека** или **Ctrl+L**. Не удаляйте папку `roms/catalog`.

В версии 3.0: каталог, поиск и избранное; CRT и послесвечение; 10 слотов и автосохранения; непрерывная перемотка до 120 секунд; ускорение и замедление; переназначение клавиш и экранная клавиатура; GIF/MP4 со звуком; проверяемые повторы ввода; точки останова, память и отчёты; перенос настроек и портативный режим.

В комплекте 210 уникальных игр, демо и программ из двух коллекций, а не все когда-либо выпущенные ROM. 199 профилей прошли ограниченную проверку запуска; 11 программ требуют других платформ. Полная инструкция: **docs/STUDIO_3_RU.md**.
