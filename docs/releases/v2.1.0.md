# CHIP-8 Studio 2.1

**Download CHIP8-Studio-Windows-x64.zip below, extract it and open CHIP8.Emulator.exe.** Windows 10/11 x64. No installation or Visual Studio required.

Two-player Pong starts immediately: **W/S** for the left paddle, **↑/↓** for the right. Use **Ctrl+O** or drag a ROM into the window for your own games. The application interface is currently Russian; the archive contains English and Russian player guides.

## What's included

- CHIP-8, Super-CHIP Modern and XO-CHIP profiles.
- Built-in two-player Pong, classic Pong, Breakout and a demo.
- Save states, rewind, fullscreen, PNG screenshots, debugging and XInput controls.
- Sprite-aware XOR stabilization, with an exact display mode available.

## Fixed in 2.1

Classic Pong and Breakout sometimes erased moving objects across display boundaries. The presentation layer now tracks each sprite independently and replaces its held position on redraw. Guest memory, collisions and instruction timing are unchanged.

Stabilization is a visual heuristic, with a maximum unmatched hold of 66.7 ms. Choose exact display for conformance tests or intentional blinking effects.

## Validation

The release workflow runs 47 core test groups, 31 offline Timendus framebuffer scenarios and native Windows window/input/save-state/fullscreen/PNG smoke checks. Physical speakers, gamepads and hardware VSync still need testing on a real user's system.

SHA256SUMS.txt contains the portable ZIP's checksum. build-info.json identifies the source commit and executable checksum. Source code is available through GitHub's source archives. Guest ROM and external test notices are retained.

## По-русски

**Скачайте CHIP8-Studio-Windows-x64.zip ниже, распакуйте и запустите CHIP8.Emulator.exe.** Windows 10/11 x64. Установка и Visual Studio не нужны.

Сразу откроется Pong на двоих: **W/S** — левая ракетка, **↑/↓** — правая. Свои ROM можно открыть через **Ctrl+O** или перетащить в окно.

В 2.1 исправлена стабилизация движущихся спрайтов в классическом Pong и Breakout. Сохранения, перемотка, снимки PNG, полный экран и отладка доступны из клавиатуры и меню.

Для намеренного мигания и тестов используйте точный экран: стабилизация может задержать исчезновение объекта максимум на 66,7 мс. Проверки ядра, ROM и оконных API выполняются перед публикацией. Физический звук, геймпады и аппаратный VSync требуют проверки на компьютере пользователя.
