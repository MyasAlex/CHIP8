**Переносимый эмулятор CHIP-8 для Windows со встроенными играми, сохранениями и перемоткой.** Скачайте ZIP, распакуйте и откройте **CHIP8.Emulator.exe**. Для готовой версии Visual Studio и отдельные DLL компилятора не нужны. Интерфейс приложения — на русском языке.

<p align="center"><img src="docs/media/gameplay.gif" alt="Pong на двух игроков в ядре CHIP-8 Studio" width="800"></p>

*Настоящие кадры ядра эмулятора с автоматическим вводом для демонстрации ракеток. Здесь показан игровой экран; у приложения есть собственное окно и меню.*

## Начать играть

1. [Скачайте CHIP8-Studio-Windows-x64.zip](https://github.com/MyasAlex/CHIP8/releases/latest/download/CHIP8-Studio-Windows-x64.zip).
2. Распакуйте весь архив в папку и запустите **CHIP8.Emulator.exe**.
3. Сразу откроется Pong на двоих. **W / S** — левая ракетка, **↑ / ↓** — правая.

Откройте свой ROM через **Ctrl+O** или перетащите файл в окно. В меню **Игры** есть также классический Pong с соперником из ROM, Breakout и анимированная демонстрация. Целевая система — Windows 10/11 x64.

## Возможности

| Возможность | Для чего нужна |
| --- | --- |
| CHIP-8, Super-CHIP и XO-CHIP | Выбор профиля совместимости и отдельных особенностей инструкций. |
| Стабилизация XOR | Уменьшает пропадания движущихся спрайтов в классическом Pong и Breakout. Для проверок можно включить точный экран. |
| Сохранения и перемотка | F5 сохраняет, F8 загружает, Backspace возвращает к недавнему снимку состояния. |
| Пиксельный экран | Целочисленный масштаб, полный экран и снимки PNG. |
| Отладка | Регистры, дизассемблирование, шаг по кадрам и инструкциям. |
| Геймпады и звук | XInput, классический сигнал и аудиоузоры XO-CHIP. |
| Работа без интернета | Игры встроены в EXE. Аккаунт и подключение к сети не требуются. |

## Основные клавиши

| Действие | Клавиша |
| --- | --- |
| Открыть ROM / пауза / перезапуск | Ctrl+O / P / F1 |
| Сохранить / загрузить / перемотать | F5 / F8 / Backspace |
| PNG / полный экран | F6 / F11; Esc возвращает окно |
| Шаг по кадру / инструкции | F9 / F10 |
| Панель отладки / выключить звук | F12 / M |

Физические клавиши **1234 / QWER / ASDF / ZXCV** соответствуют CHIP-8 **123C / 456D / 789E / A0BF**. Русская раскладка не меняет расположение управления. [Полная инструкция →](docs/USER_GUIDE_RU.md)

## Что изменилось в 2.1

Исправлена стабилизация движущихся спрайтов в классическом Pong и Breakout. Эмулятор отслеживает стирание и повторное рисование каждого спрайта отдельно. При повторной отрисовке новый спрайт заменяет старую позицию; память, столкновения и скорость игры работают как прежде.

Это визуальная эвристика: исчезновение объекта может задержаться максимум на 66,7 мс, а намеренное короткое мигание может сгладиться. В меню доступен точный экран. [Как устроено исправление и что проверено →](docs/FIX_FLICKER_RU.md)

## Проверки и совместимость

В проекте есть **47 групп тестов ядра** и **31 офлайн-сценарий Timendus**, сравнивающий кадры с эталонами C-Octo. GitHub Actions собирает и проверяет проект на Linux и Windows. Перед упаковкой Windows-версия проходит проверку оконных API, ввода, сохранений, полного экрана и PNG.

На Linux собираются ядро и тестовые инструменты; оконное приложение предназначено для Windows. Super-CHIP Legacy, CHIP-8X, MegaChip и тактовая эмуляция аппаратуры COSMAC VIP / HP48 не реализованы. Физический звук и геймпады проверяются на компьютере пользователя.
