CHIP-8 Studio 2.1 — Windows 10/11 x64

1. Распакуй весь ZIP в обычную папку.
2. Дважды нажми CHIP8.Emulator.exe.
3. Сразу откроется Pong на двух игроков. ROM и Visual Studio для этого не нужны.

Pong: W/S — левая ракетка, стрелки вверх/вниз — правая.
Автоматического соперника в этой новой игре нет.
Другие игры: меню «Игры». Свой ROM: Ctrl+O или перетащи файл в окно.

P — пауза
F1 — перезапустить текущую игру
F5 / F8 — сохранить / загрузить
F6 — снимок PNG
F11 — полный экран; Esc — вернуться в окно
F12 — панель отладки
F10 — одна инструкция; F9 — один кадр
Backspace — назад к более раннему состоянию
M — включить/выключить звук

Стандартные CHIP-8 клавиши:
1 2 3 4 / Q W E R / A S D F / Z X C V
Физические клавиши работают при русской раскладке.

Если игра рисует неправильно, выбери профиль в «Эмуляция»:
CHIP-8 (VIP), CHIP-8 (Modern), Super-CHIP (Modern), XO-CHIP 1.1.
Профиль и особенности инструкций перезапускают ROM.
Для исходного Pong/Breakout начни с Modern и 700 инструкций/с.
Для нового Pong на двух игроков оставь 6000 инструкций/с.

Меню «Экран»: точный экран или стабилизация промежуточных XOR-стираний.
Стабилизация удерживает каждый стёртый спрайт до его перерисовки.
Непарное стирание задерживается максимум на 66,7 мс. Скорость игры не меняется.
Версия 2.1 исправляет промежуточное пропадание мяча и ракеток в исходном Pong и Breakout.
Для точного экрана выберите соответствующий пункт меню «Экран».

Сохранения и настройки: %LOCALAPPDATA%\CHIP8Studio
Открыть эту папку: «Файл → Папка данных и снимков».

Готовый EXE предназначен для Windows x64.
Сборка и проверки ядра, внешних ROM и оконных API выполняются в GitHub Actions.
Физический звук, реальные геймпады и аппаратный VSync проверяются на компьютере пользователя.
